# Potato Disease Detection with XAI (Grad-CAM)

## Description
Deep learning application for potato leaf disease classification with explainable AI using Grad-CAM visualization.

## Features
- CNN-based disease classification (Early Blight, Healthy, Late Blight)
- Grad-CAM heatmap visualization
- Interactive web interface
- Real-time prediction with confidence scores

## Model Details
- **Framework**: TensorFlow/Keras
- **Input Size**: 50x50 pixels
- **Classes**: 3 (Early_Blight, Healthy, Late_Blight)
